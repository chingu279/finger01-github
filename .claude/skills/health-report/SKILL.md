# 건강 리포트

## 용도 확인
어떤 리포트인지 먼저 정한다. 청중이 다르면 내용이 완전히 달라진다.

| 용도 | 강조점 |
|---|---|
| 본인 월간 회고 | 추세, 개입 효과, 다음 달 계획 |
| **진료 전 요약** | 증상 타임라인, 측정값, 복약, 질문 목록 |
| 트레이너/코치 공유 | 훈련부하, 준비도, 부상 이력 (임상 정보 제외) |

## 데이터 수집
```bash
python -m health weekly --date <각 주의 마지막 날>   # 주별로 반복
python -m health score --json --date <날짜>
```
집계가 더 필요하면 `scripts/analysis/` 에 스크립트를 작성해 실행한다. 암산 금지.

## 진료 전 요약 (가장 유용한 형태)
의사의 진료 시간은 짧다. **한 장**에 담는다.
```
1. 오늘 온 이유 (한 문장)
2. 증상 타임라인 — 언제 시작, 어떻게 변화, 무엇이 악화/완화시켰나
3. 객관 측정값 — 혈압/체온/혈당/체중 추세 (측정 방법과 시각 포함)
4. 현재 복약 — 이름 · 용량 · 시작일 (건강기능식품 포함)
5. 시도한 것과 결과
6. 묻고 싶은 것 3가지
```
- 자가 해석과 추측 진단은 **넣지 않는다.** 관찰과 사실만 넣는다.
- 웨어러블 값은 소비자 기기 측정값임을 명시한다. 의료기기 측정값과 구분한다.

## 출력
- 텍스트/마크다운을 기본으로 한다.
- 사용자가 시각 자료를 원하면 Artifact로 발행한다.
- **어떤 리포트도 외부 서비스로 자동 전송하지 않는다.** 파일로 만들어 사용자가 직접 전달한다.

## 마지막 줄
> 이 리포트는 의료 진단이 아닙니다. 자기관리 기록이며, 판단은 의료 전문가와 함께 하세요.
